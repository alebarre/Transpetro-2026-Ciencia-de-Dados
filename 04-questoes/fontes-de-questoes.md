# Fontes de Questões – Cesgranrio

A Cesgranrio reaproveita estilo e até enunciados entre concursos. As provas abaixo cobrem o mesmo tipo de conteúdo do edital da Transpetro. Ordem de prioridade.

| Concurso | Cargo | Uso |
|---|---|---|
| **BNDES 2024** | Analista – Ciência de Dados | **Simulado 1** (a mais parecida com o edital atual: estatística, ML, Python, NLP) |
| **Petrobras 2024 e 2025** (Cesgranrio) | Ênfases de TI: Ciência de Dados / Análise de Dados / Análise de Sistemas | Simulado 2 e baterias de ML/estatística |
| **Banco do Brasil 2023** | Agente de Tecnologia | Python, SQL, ML básico, Inglês técnico |
| **Caixa 2024** | Técnico Bancário – TI | Banco de dados, SQL, Python |
| **BNB 2024** e **Banco da Amazônia 2024** | Analista de Sistemas | Banco de dados, engenharia de dados |
| **Transpetro 2023** (Cesgranrio) | Nível superior (várias ênfases) | Português e Inglês no formato exato desta prova |

Verifique no site de questões se o concurso está listado com a banca Cesgranrio antes de montar o caderno. Os nomes de cargo variam entre os sites.

## 3. Como montar os cadernos no site de questões

Filtro base: **Banca: Cesgranrio**. Depois um caderno por disciplina:

| Caderno | Disciplinas/assuntos no filtro | Meta de questões até a prova |
|---|---|---|
| Estatística | Estatística, Probabilidade | 250 |
| Machine Learning / Ciência de Dados | Ciência de Dados, Inteligência Artificial, Aprendizado de Máquina, Mineração de Dados | 300 |
| Python | Programação (Python) | 120 |
| SQL e Banco de Dados | Banco de Dados, SQL, Modelagem de Dados, Big Data | 150 |
| Português | Português (todos os assuntos) | 200 |
| Inglês | Inglês | 150 |
| Governança / Gestão / Visualização | Governança de Dados, Gestão de Projetos, BI | 60 |

Total ≈ 1.230 questões em 10 semanas ≈ 120/semana. Cabe: 20/dia útil + 40–50 no sábado.

## 5. Padrões da Cesgranrio a reconhecer

- Enunciado longo com contexto de empresa; a pergunta está na última frase. **Leia a última frase primeiro.**
- Cinco alternativas plausíveis; costuma haver duas absurdas, duas próximas e uma correta. Elimine as absurdas antes de pensar.
- Em código Python/SQL: o erro geralmente está em índice (0-based), em `axis`, em NULL/NaN, ou em um JOIN que multiplica linhas. Rode mentalmente linha a linha.
- Em estatística: pede-se conta pequena com números redondos. Se o resultado ficou feio, você errou a fórmula.
- Em Português: valoriza interpretação, coesão e norma culta (crase, concordância, regência). Questão de gramática quase sempre está ancorada num trecho do texto.
- Em Inglês: texto de 30–50 linhas sobre tecnologia/energia/negócios; perguntas sobre ideia principal, referência de pronome, significado de palavra no contexto, e "de acordo com o texto, é correto afirmar".
